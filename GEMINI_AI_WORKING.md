## 📈 Quota Management

### Free Tier Limits
- **15 requests per minute** (RPM)
- **1500 requests per day** (approximate)
- Resets every 24 hours

### How App Manages Quota

#### Smart Caching
- First request → Calls Gemini API
- Next 10 requests (30 min) → Returns cached response
- **Saves 90% of API calls**

#### Rate Limiting
- Tracks requests per minute
- Waits if limit reached
- Prevents quota exhaustion

#### Graceful Fallback
- If quota exceeded → Uses static responses
- Users never see errors
- All features remain functional

## 💡 Best Practices

### To Maximize API Quota:

1. **Use During Testing**
   - Test AI features when needed
   - Don't spam chatbot with rapid requests
   - Each message = 1 API call

2. **Leverage Caching**
   - Same query within 30 min = cached (free)
   - Daily tips cached for 24 hours
   - Encourages users to explore once, then cache serves others

3. **Monitor Usage**
   - Check server logs for API call count
   - Look for: `📊 API Request X/10`
   - If seeing rate limits often = consider upgrade

4. **Upgrade if Needed** (Optional)
   - Enable billing in Google Cloud Console
   - Cost: ~$0.50 per 1000 requests
   - Removes daily quota
   - Higher rate limits (60 RPM)
