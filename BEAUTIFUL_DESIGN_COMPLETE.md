## 🎯 Technical Implementation

### CSS Custom Properties
```css
--color-primary: #2d5016 (Dark Forest Green)
--color-accent-wheat: #f4e4c1 (Wheat Gold)
--color-accent-sky: #87ceeb (Sky Blue)
--shadow-xl: 0 12px 24px rgba(45, 80, 22, 0.2)
```

### Gradient Patterns
```css
Login Background:
  linear-gradient(135deg, #87CEEB 0%, #98D8E8 50%, #F4E4C1 100%)

Register Background:
  linear-gradient(135deg, #87CEEB 0%, #98D8E8 30%, #B8E6B8 60%, #F4E4C1 100%)

Button Gradient:
  linear-gradient(to right, #10b981, #059669, #047857)
```

### Animation Timings
```css
bounce: 3s - 4s (different delays)
pulse-glow: 2s infinite
fade-in-up: 0.6s ease-out
shake: 0.5s (on error)
```
