□ STEP 1: Push to GitHub

  □ Run: git push -u origin main

□ STEP 2: Deploy Backend
  □ Run: .\deploy-backend.ps1
  □ Or: cd server && vercel --prod
  □ Copy backend URL
  □ Add environment variables in Vercel Dashboard:
    □ NODE_ENV=production
    □ MONGODB_URI=(your connection string)
    □ JWT_SECRET=(your secret)
    □ GEMINI_API_KEY=(your key)
    □ OPENWEATHER_API_KEY=(your key)
    □ CLOUDINARY credentials
    □ Google Sheets URLs
    □ CORS_ORIGIN=(will update later)

□ STEP 3: Deploy Frontend
  □ Run: .\deploy-frontend.ps1
  □ Or: cd client && vercel --prod
  □ Enter backend URL when prompted
  □ Copy frontend URL
  □ Add environment variable in Vercel:
    □ REACT_APP_API_URL=(backend URL)/api

□ STEP 4: Configure MongoDB Atlas
  □ Go to: https://cloud.mongodb.com
  □ Network Access → Add IP Address
  □ Allow: 0.0.0.0/0
  □ Confirm

□ STEP 5: Update CORS
  □ Go to Vercel → Backend Project
  □ Settings → Environment Variables
  □ Edit CORS_ORIGIN to frontend URL
  □ Deployments → Redeploy
