## 🚨 Troubleshooting

### Issue: "Still getting 429 error"
**Solution**: 
- Make sure you copied the ENTIRE key
- Check no extra spaces in .env file
- Restart server completely
- Clear browser cache

### Issue: "Key not found error"
**Solution**:
- Verify key starts with `AQ.`
- Check you're signed in to AI Studio with NEW account
- Try creating key again

### Issue: "Invalid key format"
**Solution**:
- Make sure no quotes around key in .env
- Should be: `GEMINI_API_KEY=AQ.Ab8...`
- Not: `GEMINI_API_KEY="AQ.Ab8..."`
