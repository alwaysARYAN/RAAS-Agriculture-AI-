## 🔧 Customization:

### To change cloud speed:
Edit `client/src/aqua-theme.css` line 60-85:
```css
animation: driftLeft 60s linear infinite; /* Change 60s to your desired speed */
```

### To change avatar bounce:
Edit `client/src/aqua-theme.css` line 110:
```css
animation: avatarBounce 3s ease-in-out infinite; /* Change 3s to your desired speed */
```

### To adjust card hover effect:
Edit `client/src/aqua-theme.css` line 156:
```css
transform: translateY(-12px) rotate(1deg) scale(1.02); /* Adjust values */
```

### Issue: Cards not lifting on hover?
**Solution**: Ensure mouse hover is working, not touch device

**Solution**: Wait for Google Fonts (Poppins, Quicksand) to load
