## 💡 Pro Tips

### **Layering**
Stack glass effects for depth:
```jsx
<div className="glass-card">
  <div className="glass-card-hover">
    Nested depth
  </div>
</div>
```

### **Animation Stacking**
Combine multiple animations:
```jsx
<div className="fade-in-up float-widget card-3d">
  Triple effect!
</div>
```

### **Responsive Glow**
Adjust glow intensity by viewport:
```jsx
<div className="shadow-glow-sm md:shadow-glow-lg">
  Responsive glow
</div>
```
